编译方法

使用 XeLaTeX，连续编译两次 main.tex，以解析引用和编号。
应安装 fontspec、xeCJK、TikZ、listings、booktabs、balance 等常见 TeX Live 宏包。
本机已使用 TeX Live 2026 编译验证。Windows 优先使用宋体、黑体、Times New Roman 和 Consolas；其他环境自动回退到 TeX Live 的 Fandol 与 TeX Gyre/Latin Modern 字体，不需要修改正文。

例如在此目录打开 PowerShell，执行：

$reportBuild = Join-Path $env:TEMP 'advancedos-report-build'
New-Item -ItemType Directory -Path $reportBuild -Force | Out-Null
xelatex -interaction=nonstopmode -halt-on-error "-output-directory=$reportBuild" main.tex
xelatex -interaction=nonstopmode -halt-on-error "-output-directory=$reportBuild" main.tex

编译后的文件位于临时目录中的 main.pdf。确认内容后另存为需要的提交文件名；命令不会覆盖本目录已交付的 PDF。
