# 块设备与平台适配工作说明

负责人：周梦武。日期：2026-10-20。

## 此前已有的工作

- RISC-V 三台 VirtIO 设备管理：dev=1 为原生根盘，dev=2/3 为数据盘，独立队列与锁。
- D1 字节读写、容量与刷新接口，非对齐、跨扇区与部分扇区读改写，边界检查、只读和根盘写保护。
- LoongArch 独立启动、串口、异常入口、定时器、现场恢复/ertn 与上下文切换探查。

上述功能已在原 hal-platform 中，此包保留它们，不能全部算作本次新增。

## 本次新增与修复

- 修复 D1 对齐 I/O 直接把调用方内核虚拟地址用于设备传输的问题，改为每设备固定扇区缓冲区中转。
- 增加内核栈缓冲区读取、写入与读回比较测试。
- 统一回归自动运行宿主并发与 ASan/UBSan 检查，记录源码和 Makefile 哈希，遇到内核 panic 及时失败。
- 为已有 LoongArch 五类探查增加统一构建、运行、串口标记检查和日志收集脚本，并实际复验。
- 补充本次结果、复现方法及相对个人原分支的提交清单。

## 验证边界

本轮重新测试的是个人 hal-platform 基础上的独立模块，没有携带 A 的 VFS 或 B 的 ext2。此前三方集成候选中的一次内核异常仍需另行跟踪；个人模块通过不能用于关闭该问题。

LoongArch 仍为独立机制探查，尚未完成页表、内存、用户态、调度器与磁盘的完整内核接入。文件系统后端挂载、ext2/FAT32 实现不是本次个人新增工作。

复现：按根 README 运行 python3 tests/run_c_tests.py（在 xv6-riscv 内）及探查目录内的 python3 run_probes.py。原始日志、工具配置和源码哈希见 block-device-and-loongarch/证据/20261020。
